<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| daemon → EchoSession DO (WS) | Untrusted outbound WebSocket from the local capture app crosses into the cloud |
| daemon → presign endpoint | OAuth-bearer request asking the cloud to grant write access to R2 |
| presign URL → R2 | A time-limited capability handed to the daemon for direct upload |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-02-01 | Spoofing | Stale EchoSession WS reused after meeting end | mitigate | webSocketClose persists `finalized:${sessionId}`; finalize is the terminal signal — a new WS to a finalized session has no further effect on the transcript (segments are frozen) |
| T-03-02-02 | Information Disclosure | Leaked presigned URL (valid 1h) | mitigate | URL scoped to one exact Key; expiresIn 3600; Key MUST start with transcripts/ or audio/raw/ (else 400) — never an arbitrary-key presign |
| T-03-02-03 | Elevation of Privilege | presign endpoint without scope check | mitigate | grantedScopes(ctx.props.scopes).has("echo:presign") fail-closed 403; session_id must exist in D1 meetings before minting |
| T-03-02-04 | Information Disclosure | R2 credentials in config | mitigate | R2_ACCESS_KEY_ID / R2_SECRET_ACCESS_KEY via Secrets-Store bindings only (await .get()), never [vars]/KV/tracked file |
| T-03-02-05 | Elevation of Privilege | second atlas-wire consumer | mitigate | Echo is producer-only; index.ts has NO queue() handler; wrangler has NO consumers block (verified in 03-01); PreToolUse guard hook backstops |
| T-03-02-SC | Tampering | @aws-sdk/client-s3 + @aws-sdk/s3-request-presigner install | mitigate | Both [OK] in 03-RESEARCH Package Legitimacy Audit (AWS official, ~4yr, no postinstall); pinned 3.1063.0 |
</threat_model>
