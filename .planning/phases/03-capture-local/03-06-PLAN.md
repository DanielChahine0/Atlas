<objective>
Build Quill: hotkey-triggered on-screen autofill from the LOCAL Codex, AX-first with
an on-device OCR fallback, stopping at a review panel and NEVER submitting. Covers
CAPTURE-02. Quill is the second native surface in the shared capture runtime (D6 —
no Echo data dependency), so it builds on the 03-04 shell + the local Codex cache and
runs independently of Echo (03-05).

Purpose: Proves the local-capture privacy boundary for screen content — screen data
never leaves the device; no cloud LLM ever sees the screen; no cloud round-trip in the
fill loop; Quill never writes the Vault/Wire/Codex and never clicks Submit. v1 covers
native apps + accessibility-friendly web via AX/OCR (D3-07 — the browser-extension DOM
bridge is deferred).
Output: A hotkey-driven autofill + review-panel pipeline; verification is XCTest
(field mapping, secret refusal, confirm-before-submit) + owner UAT on real forms.

NOTE (autonomous:false): AX tree read, value injection, OCR, and the SwiftUI review
panel require a physical macOS runtime + a live focused form + Accessibility/Screen-
Recording grants — owner-UAT per 03-VALIDATION Manual-Only. The Codex field mapping,
secret-refusal, EEO-blank, and confirm-before-submit invariants ARE XCTest-unit-testable
(pure logic). Owner go-live gates (not tasks): Accessibility + Screen-Recording grants.
</objective>

AX read + value injection (RESEARCH Pattern 6; ref developer.apple.com/.../axuielement):
  AXUIElementCreateSystemWide() -> focused app -> focused window -> walk for AXTextField/AXTextArea, etc.
  Inject (only after review-panel confirm): AXUIElementSetAttributeValue(element, kAXValueAttribute, value)
  -> on err != .success report a P3 "value injection rejected" via IncidentRelay (form + field label only).

OCR fallback (RESEARCH Pattern 6; ref developer.apple.com/.../vnrecognizetextrequest):
  VNRecognizeTextRequest(recognitionLevel: .accurate, usesLanguageCorrection: true) over a window capture;
  use boundingBox to associate labels spatially with inputs when there is no AX tree. Fully on-device.

Codex field map (D3-08, D3-09; docs/agents/quill.md; docs/07-source-of-truth-codex.md §11):
  Read ONLY the local Codex disk cache from capture/Sources/Shared/CodexCache.swift (03-04) — NO cloud
  round-trip in the fill loop, NO cloud LLM. Normalize each field label -> a Codex field (identity/
  education/work/skills/projects/bios/socials). Free-text "voice" fields (cover letter / "Why this role?")
  -> a DETERMINISTIC local Codex bio/voice-note snippet insert marked low-confidence "review voice"
  (NO generative model). autofill_eeo = false (EEO/demographics left blank). REFUSE secrets
  (password/SSN/payment) -> do not fill, raise a P2 via IncidentRelay (form + field label only, never the value).

Review + submit lock (D3-09; Pillar 2):
  confirm_before_submit = true is LOCKED, not user-disablable. Quill stops at a SwiftUI review panel with
  per-field confidence (mask_sensitive_in_panel for any sensitive field); on multi-page/wizard forms,
  re-scan the AX tree PER STEP and fill page-by-page. There is NO code path that clicks Submit/Apply/Send.
  Quill NEVER writes the Vault, the Wire (only IncidentRelay flags via atlas-incidents), or the Codex.

Hotkey (Quill is on-demand, never autonomous): a global hotkey monitor in QuillController triggers a scan;
  Quill does nothing until the owner presses it.
