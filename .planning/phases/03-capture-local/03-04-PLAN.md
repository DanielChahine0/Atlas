<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| capture app -> cloud | Every connection is OUTBOUND from the laptop; the laptop has NO inbound port |
| Keychain -> daemon | The OAuth bearer is hardware-backed on Apple Silicon; never in a tracked file |
| IncidentRelay -> atlas-incidents | A flag may name a form + field labels but never screen content/values |
| CodexCache -> disk | A local read-only Codex snapshot; Quill's fill loop must not round-trip to the cloud |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04-01 | Elevation of Privilege | capture daemon as an inbound attack surface | mitigate | No inbound port: plist has no Sockets/ListenStream/NetworkBindTimeout; all connections outbound; `lsof -i -nP \| grep LISTEN` proof at go-live (gating criterion) |
| T-03-04-02 | Information Disclosure | OAuth token storage | mitigate | macOS Keychain (SecItem*) only; never UserDefaults/plist/[vars]/Vault/Codex; D3-02 least-privilege client (a leaked capture token cannot touch the Vault outbox) |
| T-03-04-03 | Information Disclosure | screen content leaking via a Quill/Echo incident flag | mitigate | IncidentRelay.swift strips values before emit — form name + field labels only; IncidentRelayTests is the assertion backstop; code review |
| T-03-04-04 | Tampering | dropped/duplicated outbound command on transient error | mitigate | Serial drain, ack ONLY after successful execute, back off + leave pending on error (never drop); OutboxChannelTests asserts no-ack-on-failure |
| T-03-04-05 | Spoofing | a forged cloud command to the daemon | mitigate | Daemon initiates all connections + uses default cert validation on outbound HTTPS; it does not accept inbound requests, so there is no inbound surface to spoof |
| T-03-04-SC | Tampering | SPM dependency resolution (WhisperKit/FluidAudio) | mitigate | Pinned `from: "1.0.0"` / `from: "0.15.1"` from official GitHub repos (argmax-oss-swift, FluidInference/FluidAudio); not the npm ecosystem; legacy WhisperKit URL explicitly avoided |
</threat_model>
