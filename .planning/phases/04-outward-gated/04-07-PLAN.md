<objective>
Build `apps/envoy` (OUTWARD-02) — the on-demand personal-brand publisher. It fans ONE owner intent ("I started/shipped <project>") into up to four targets (LinkedIn, GitHub profile README, X, portfolio PR), drafts each literal artifact from the Codex, opens ONE ~7d gate with per-target approve/edit/skip, and on approval publishes ONLY the approved targets: GitHub via mcp-github (agent completes — README commit + portfolio PR, D4-10), LinkedIn/X via a local browser pre-fill the owner finalizes (owner clicks Post, D4-08). Bumps the Steward Brand counters.

Purpose: OUTWARD-02 — fan one intent into per-channel drafts from the Codex and ship only on confirmation; a public post can't be un-posted, so nothing posts silently. Depth scales with reversibility: reversible GitHub PR/README the agent completes; irreversible LinkedIn/X posts the owner clicks Post.

Output: `apps/envoy/` WorkerEntrypoint (index.ts + draft.ts + github.ts + browser.ts) + scaffold + the named Wave 0 test. Mirrors the Headhunter WorkerEntrypoint shape.

Pillar 1: Wire PRODUCER only — NO `queues.consumers` on atlas-wire. Writes GitHub DIRECTLY via mcp-github; bumps counters via a Wire event Steward applies. Reads the Codex read-only.
</objective>
