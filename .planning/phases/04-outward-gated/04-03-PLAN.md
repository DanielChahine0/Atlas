<objective>
Build `apps/gate` — the dedicated Worker that serves the token-gated confirm page (GET/POST `/confirm`), runs the expiry-sweep `scheduled()`, and hosts the browser-action poll/ack endpoints the local daemon drains (`/browser/poll`, `/browser/ack`). It is the single, stable-hostname surface the owner's push link opens and the single place the gate decision is committed and the owning agent re-invoked.

Purpose: D4-01/D4-02 — one Worker, one stable confirm URL, fail-closed decision commit, no live browser held across the human pause. Mirrors Flagger's `fetch()` + `scheduled()` dual-handler shape exactly. The gate Worker is a Wire PRODUCER only (re-invokes agents; agents emit their own Wire events) — it MUST NOT declare a `queues.consumers` block on `atlas-wire` (Pillar 1).

Output: `apps/gate/` Worker (package.json, tsconfig, wrangler.jsonc, src/index.ts) + the named Wave 0 test file `apps/gate/src/index.test.ts`.

Hosting decision (resolved): one `apps/gate` Worker, not per-agent — one place to audit the fail-safe, one stable confirm hostname, and the expiry cron lives here (it already has DB + INCIDENTS bindings). Same shape as Flagger.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| owner's browser (push link) → GET/POST /confirm | untrusted token + form decision cross the open internet |
| local daemon → /browser/poll, /browser/ack | Bearer-token-authenticated outbound poll (no inbound port on the laptop) |
| gate Worker → USHER/ENVOY/SUNDIAL | trusted service-binding RPC re-invoke on approval |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-11 | Tampering | fail-open on POST /confirm error | mitigate (HIGH) | decideGate atomic batch commits before side effect; catch → 500 + "no action taken" page; failed re-invoke records outcome='error' + P2, never silent success (Task 2, --grep fail-closed) |
| T-04-12 | Tampering | CSRF on confirm POST | mitigate | isSameOrigin() fail-closed 403; AUTH_SECURITY_HEADERS referrer-policy no-referrer (Task 2) |
| T-04-13 | Tampering | expired-gate race (approve after deadline) | mitigate | getGate requires status='pending'; expires_at checked; sweep flips to expired; expired GET → 410, POST → no pending row (Task 2, --grep expire) |
| T-04-14 | Spoofing | unauthenticated /browser/poll or /browser/ack | mitigate | constant-time Bearer check against GATE_CONFIRM_TOKEN; 401 fail-closed if unseeded (Task 2) |
| T-04-15 | Tampering | browser action firing without an approved gate row | mitigate | /browser/poll only returns browser_action_outbox rows; those rows are written ONLY by the agent's post-approval path (04-06/04-07); orphan = P1 self-flag invariant carried in Usher/Envoy plans |
| T-04-16 | Information Disclosure | 2FA/reset/login URL in confirm page | mitigate | renderConfirmPage redacts (04-01); gate Worker never reads email bodies, only the agent-drafted artifact |
| T-04-17 | Elevation of Privilege | second atlas-wire consumer | mitigate | no queues.consumers on atlas-wire in apps/gate; guard-wire-consumer.js gate (Task 1) |
| T-04-SC | Tampering | new package install | accept | No new package — uses @atlas/gate + existing deps |
</threat_model>
