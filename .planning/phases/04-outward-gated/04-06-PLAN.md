<objective>
Build `apps/usher` (OUTWARD-01) — the on-demand event-registration agent. A light "cloud-brain" WorkerEntrypoint: resolve the event, disclose the price, open a ~24h gate, and only on the owner's confirm enqueue a local browser action (event_fill_submit) that the daemon (04-04) auto-submits in the owner's logged-in session; scrape the confirmation #; add the event to Google Calendar via mcp-google; bump the Steward `events-registered` counter. Hard stops (captcha/payment/sold-out/login-wall/ToS) always override even after a yes.

Purpose: OUTWARD-01 — on-demand search + gated registration + Calendar add + counter, gate adherence = 100%, captcha/payment hard stops handed back. No outward action fires without an explicit owner confirm; nothing is registered without a scraped confirmation #.

Output: `apps/usher/` WorkerEntrypoint (index.ts + fill.ts + calendar.ts) + wrangler/package/tsconfig + the named Wave 0 test `apps/usher/src/index.test.ts`. Mirrors the Headhunter WorkerEntrypoint shape (on-demand, no cron, no queue consumer).

Pillar 1: Usher is a Wire PRODUCER only — NO `queues.consumers` block on atlas-wire. Writes Calendar DIRECTLY via mcp-google (not via Steward/Sundial); bumps the counter by emitting a Wire event that Steward (the sole consumer) applies.
</objective>
