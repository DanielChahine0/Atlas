<objective>
Retrofit Sundial's existing gated-removal proposal onto the shared `packages/gate` primitive (D4-04) — Sundial is the proof that the gate UX matured on a lower-stakes action before Usher/Envoy use it for outward-irreversible actions. Purpose: Proves the gate primitive end-to-end on a real existing consumer before the outward agents depend on it, and consolidates the only existing "propose-removal" path onto the single enforcement point. NOTE the hard ROADMAP edge: "gate-UX maturity before Usher/Envoy" — this retrofit IS that maturity demonstration.

Output: a modified `apps/sundial/src/index.ts` (the caller calls openGate per propose-removal; adds an `applyRemoval()` re-invoke entrypoint) + an added gate-retrofit test. `reconcile.ts` is NOT changed.

Critical constraint (Pitfall 7): `reconcile()`'s signature and `propose-removal` decision type do NOT change; the existing P2 `flag()` stays (the gate is additive); the existing Wire-contract / replay / failure-path Sundial tests MUST still pass.
</objective>
