<objective>
Build Sundial (`apps/sundial`) — the task → Google Calendar sync. One new Worker exposing a `sync` RPC method (the `sundial-sync` Workflow step's target) that reads Forge's deadline tasks from D1 (via `@atlas/tasks`), lists only its OWN existing blocks (server-side filtered by `privateExtendedProperty agent=sundial`), maps each task to a calendar block, reconciles by `atlasTaskId` (create / patch / skip), and emits a `calendar.sync` event. Sundial holds `calendar.events` only (no delete on the autonomous path); a re-run is idempotent (no duplicate events). No model is required — the mapping is deterministic.

Purpose: Sundial puts deadlines on the calendar where the owner already lives, deduped so the daily re-run never spams duplicates. The no-delete + own-events-only invariants keep it inside Pillar 2 and the one-writer rule.
Output: the `apps/sundial` Worker, the block-mapping + reconcile modules, and the three DoD tests (reconcile/no-dup, Wire-contract, idempotency).
</objective>
