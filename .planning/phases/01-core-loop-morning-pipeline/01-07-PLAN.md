<objective>
Build Compass (`apps/compass`) — the daily planner and last chain stage. One new Worker exposing a `plan` RPC method (the `compass-plan` Workflow step's target) plus an independent 21:00 `preview` cron. It reads open tasks (D1 via `@atlas/tasks`) + today's calendar (read-only) + Codex prefs, scores tasks, builds a free/busy grid, bin-packs a time-blocked plan with a top-3, handles overcommitment with a visible "⚠ Couldn't fit today" list + a P3, and emits a `day_plan` event that drives the Vault Today view + morning-glance top-3. Compass holds `calendar.readonly` only (never writes the calendar). Per D1-05, Opus runs at `effort=medium` by default, overridable via the KV key `compass.effort` — never `high` as the daily default.

Purpose: Compass is the payoff of the chain — the owner's "what do I actually do today." Its overcommitment handling (surface, never drop) and read-only-on-calendar discipline are core invariants; the effort tuning controls the dominant cost (the Claude bill).
Output: the `apps/compass` Worker, the scoring/grid/plan modules, and the three DoD tests (overcommit, Wire-contract, effort).
</objective>
