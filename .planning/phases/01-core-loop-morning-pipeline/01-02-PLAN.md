<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Forge/Sundial/Compass → @atlas/tasks → D1 | Task data crosses into the system-of-record; must use parameterized queries (no string interpolation) and stay in D1, never KV. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-D1-01 | Tampering (SQL injection) | store.ts queries | mitigate | All queries use db.prepare(sql).bind(...) anonymous positional ? params — never string interpolation of task fields. |
| T-1-D1-02 | Information Disclosure | task store location | mitigate | Tasks live in D1 (system-of-record), never KV; no credentials/2FA/codes stored (Forge security-skip filters those upstream). |
| T-1-D1-03 | Repudiation / duplicate state | dedupe | mitigate | idx_tasks_dedupe unique index + merge-on-collision path guarantee one row per (thread,title,due); replay-safe. |
| T-1-D1-SC | Tampering | npm installs | accept | No new package installs (WebCrypto is built-in; tooling mirrors existing workspace packages). |
</threat_model>
