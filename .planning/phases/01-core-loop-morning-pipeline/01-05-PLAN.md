<objective>
Build Forge (`apps/forge`) — the task/subtask extractor. One new Worker exposing a `morning` RPC method (the `forge-morning` Workflow step's target) that takes Herald's digest items + thread refs, filters the `① Action Required` set carrying `Needs/*`/`Due/*`, extracts `{title, subtasks[], priority}` (Sonnet), infers deadlines, dedupes/merges into the D1 `tasks` store (via `@atlas/tasks` from Plan 02) inside a per-run DO lock, and emits one Wire event per new/changed task keyed on the task id. Forge creates tasks only — it never touches Gmail/calendar/Vault directly, and it security-skips any item whose only actionable content is a code/link.

Purpose: Forge turns the digest into deadline-safe tasks (the system-of-record Sundial and Compass both read). Its dedupe discipline is what makes the daily re-run idempotent (no duplicate tasks).
Output: the `apps/forge` Worker, the extraction + deadline-inference modules, and the three DoD tests (dedupe, Wire-contract, security-skip).
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Digest/thread content → Forge extraction | Untrusted email content drives LLM extraction; a 2FA code / reset link must never become a task field. |
| Forge → D1 tasks store | Parameterized writes only; dedupe must prevent duplicate state on re-run. |
| Forge → Wire → Steward | Per-task events must be replay-safe (idempotencyKey = task id). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-SEC-08 | Information Disclosure | task extraction | mitigate | Security-skip: an item whose only content is a code/link is dropped; a ⚠ Phishing-Suspect thread is not extracted and raises P2. No task field ever contains a code/reset URL (CI security.test.ts). |
| T-1-D1-04 | Repudiation / duplicate state | dedupe/merge | mitigate | dedupeKey + idx_tasks_dedupe unique index + merge path → one task per (thread,title,due); re-run emits no duplicate. |
| T-1-SEC-09 | Tampering | Forge scope | mitigate | Forge reads Gmail labels only (gmail.readonly); never labels/sends/registers/pays; never writes the Vault directly (events via Steward). |
| T-1-SEC-SC | Tampering | npm installs | accept | No new package installs (RESEARCH Package Legitimacy Audit). |
</threat_model>
