| /switchboard recommendation → executing agent | The recommendation tells a human which agent should execute and whether a gate is required |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-Switch-Elev | Elevation of Privilege | /switchboard allowed-tools | mitigate | allowed-tools is READ-ONLY (Read, Glob, context7, WebSearch) — NEVER Write/Edit/Bash. The command recommends, never acts (Pitfall 5). Verified by the grep gate. |
| T-5-Switch-Gate | Tampering | recommendation for outward intents | mitigate | Hard rule in the algorithm: any intent with a `side_effect_verb` ALWAYS carries `confirmation_gate: true` + the executing agent (Pillar 2). An ungated outward toolset is a P1 gap, not a silent recommendation. |
| T-5-Switch-Writer | Elevation of Privilege | recommended toolset | mitigate | Hard rule: NEVER recommend a second writer for a resource an existing agent owns (Pillar 1) — driven by the registry `owning_agents` field. |
| T-5-Switch-Pillar1 | Elevation of Privilege | gap→Flagger emit path | mitigate | The gap emit reuses the existing producer-only `flag()` / `atlas-incidents` path (D-07); NO new `atlas-wire`/`atlas-incidents` consumer is introduced (Switchboard is not a deployed Worker — D7). |
| T-5-SC | Tampering | npm/pip/cargo installs | mitigate | No packages installed — Switchboard ships as a tracked JSON + a markdown slash-command + a doc edit. No code, no Worker, no install task (RESEARCH Package Legitimacy Audit: none). |
