<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Design-time operator → /switchboard command | A goal string crosses into a routing recommendation that could (if mis-specified) recommend an ungated outward action |
| /switchboard recommendation → executing agent | The recommendation tells a human which agent should execute and whether a gate is required |
| Emitted gap RawIncident → operator one-command emit → atlas-incidents | The operator copy-pastes a Switchboard-shaped §6.4 incident into a producer-only emit; no automated write path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-Switch-Elev | Elevation of Privilege | /switchboard allowed-tools | mitigate | allowed-tools is READ-ONLY (Read, Glob, context7, WebSearch) — NEVER Write/Edit/Bash. The command recommends + emits JSON, never acts (Pitfall 5). Verified by the grep gate. |
| T-5-Switch-Gate | Tampering | recommendation for outward intents | mitigate | Hard rule in the algorithm: any intent with a `side_effect_verb` ALWAYS carries `confirmation_gate: true` + the executing agent (Pillar 2). An ungated outward toolset is a P1 gap, not a silent recommendation. |
| T-5-Switch-Writer | Elevation of Privilege | recommended toolset | mitigate | Hard rule: NEVER recommend a second writer for a resource an existing agent owns (Pillar 1) — driven by the registry `owning_agents` field. |
| T-5-Switch-Pillar1 | Elevation of Privilege | gap→Flagger emit path | mitigate | The actionable gap emit reuses the existing producer-only `flag()` / `atlas-incidents` PRODUCER (D-07); the command emits a §6.4 RawIncident JSON + documents a one-command producer-only emit; NO new `atlas-wire`/`atlas-incidents` consumer is introduced (Switchboard is not a deployed Worker — D7). |
| T-5-SC | Tampering | npm/pip/cargo installs | mitigate | No packages installed — Switchboard ships as a tracked JSON + a markdown slash-command + a doc edit + a Vitest test using existing workspace devDeps. No code Worker, no install task (RESEARCH Package Legitimacy Audit: none). |
</threat_model>
