### 🔴 INT-BLOCKER-1 — `Forge.createTask` not implemented (affects WEEKLY-01)
- **Caller:** `apps/headhunter/src/index.ts:204,306` → `env.FORGE.createTask(...)` (typed at `:55`).
- **Target:** `apps/forge/src/index.ts:241` `class Forge extends WorkerEntrypoint` exposes **only** `async morning()` — no `createTask` (exhaustive grep: 0 hits).
- **Impact:** runtime `TypeError`; Headhunter cannot create apply-by tasks; WEEKLY-01 job-tracking half non-functional.
- **Why it slipped:** Headhunter tests stub `FORGE` as `{createTask: vi.fn()}`; Phase-2 VERIFICATION + 02-SECURITY (T-02-hh3) verified the *call site* only, never the *target method*.
- **Fix:** add `async createTask(task, opts)` to the Forge WorkerEntrypoint, delegating to the existing `upsertTask`/`taskIdFor`/`buildTaskEvent` pipeline.

### 🟡 INT-WARN-1 — 5 Phase-1 wranglers missing `database_id` (affects CORE-01 + FILER/HERALD/FORGE/SUNDIAL/COMPASS)
- `filer/herald/forge/sundial/compass` declare `database_name: atlas-db` but omit `database_id`; every Phase-0/2 app carries `e7fee76c-2e3d-486e-8a8a-fd1aec6a5af3`.
- **Impact:** `wrangler deploy` fails or binds an isolated D1 → Forge writes tasks Sundial/Compass can't read. Local/test unaffected.
- **Fix:** add the `database_id` line to each of the five.

### 🟡 INT-WARN-2 — Monday Headhunter dual-fire (affects WEEKLY-01)
- Crons `"0 13 * * *"` and `"0 13 * * 1"` share the Monday slot → both `deadlines()` and `full()` run. Steward dedups, but it's undocumented overhead. Document or guard.
